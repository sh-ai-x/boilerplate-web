saas - Setup & Deploy Guide

Stay open in your browser while running these commands in another terminal.

Step 0 - Scaffold (one line)

npx create-boilerplate-web ./my-saas --type=saas --yes --allow-unsafe-path --skip-install --deploy

Step 1 - Install deps (pnpm, not npm)

WARNING: Don't run npm install - fails with EUNSUPPORTEDPROTOCOL: workspace:*. This boilerplate uses pnpm workspaces.
cd ./my-saas
npm install -g pnpm     # if you don't have pnpm (one-time)
pnpm install

Step 2 - Fill in .env.local (13 keys, 4 dashboards)

cp .env.example .env.local
$EDITOR .env.local
Where to get each key (4 dashboards)
  • Supabase: dashboard -> new project -> Settings API + Settings General + Account Tokens
  • Vercel: signup with GitHub -> Account Settings for org id, account/tokens for token
  • Cloudflare: add domain -> Account ID + Zone ID, profile/api-tokens for zone-WAF token
  • Toss: tosspayments.com developer dashboard, API keys for Live Secret + Auth

Step 3 - Verify prereqs

./scripts/setup.sh --check

Should print: prereqs OK, run without --check to execute setup.

Step 4 - Run setup

export GH_REPO_NAME=my-saas
./scripts/setup.sh

Does: supabase link + db push + functions deploy billing + git init/commit + gh repo create/push + gh secret set x7.

Step 5 - Push to default branch (trigger first deploy)

If setup.sh already pushed (gh repo create --push), skip ahead. Otherwise:

git remote add origin https://github.com/<OWNER>/<REPO>.git
git branch -M default-branch-name
git push -u origin default-branch-name

Step 6 - Watch first deploy

gh run watch --repo "<OWNER>/<REPO>"

3 jobs: deploy-shared (Vercel + CF Pages), supabase-functions (billing), cloudflare-waf.

Step 7 - Import Vercel project (one-time)

  1. vercel.com/dashboard
  2. Add New -> Project
  3. Pick the repo
  4. Accept Next.js build settings
  5. Deploy

After deploy, verify with:

open "$(gh api repos/<OWNER>/<REPO> --jq .homepage)"

Step 8 - Verify Supabase + Cloudflare WAF

supabase functions list --project-ref "$SUPABASE_PROJECT_REF"

Cloudflare: dash.cloudflare.com -> zone -> Security -> WAF -> Custom Rules should show 6 rules.
